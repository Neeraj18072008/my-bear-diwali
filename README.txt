MY BEAR — DIWALI SURPRISE WEBSITE
=================================

FILES
- index.html: all four pages and content
- style.css: responsive styling and animations
- script.js: page navigation, sparkles and envelope interaction
- assets/photos/: put your shared photos here

ADD YOUR PHOTOS
Your three uploaded photos have already been added to assets/photos as photo1.jpg, photo2.jpg and photo3.jpg. Open index.html in a browser to preview.

PERSONALIZE
- Search in index.html for "My Bear" to change the nickname.
- Search for "Neeraj" to change the signature.
- Edit the letter text directly in index.html.

PREVIEW
Double-click index.html. For a local server, open a terminal in this folder and run:
  python -m http.server 8000
Then visit http://localhost:8000

PUBLISH
Upload the folder to GitHub and deploy with Render static site, or use GitHub Pages.
The website is static and needs no API key or backend.

PRIVACY
This template does not upload photos anywhere by itself. If you publish the site,
anyone with the public link may be able to view the photos, so only use pictures
you are comfortable sharing on that link.
